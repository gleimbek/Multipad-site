Escribe código en varias ventanas a la vez, en cualquier dispositivo

Multipad es un editor de código gratuito al estilo de Notepad++. Divide cada ventana hasta en cuatro paneles, abre otra ventana en tu segundo monitor y ejecuta HTML, JavaScript, Python y SQL sin salir del editor.

Versión 1.7.0. Gratis, sin crear cuenta, en español, inglés, portugués o francés.

Lo que hace distinto a Multipad

La idea viene de Notepad++, pensada para quien trabaja con más de una pantalla o cambia de dispositivo durante el día.

Paneles y ventanas

Hasta cuatro paneles por ventana y una ventana en cada monitor. Arrastra pestañas de una ventana a otra.

Ver todas las funciones

Ejecuta tu código

HTML, JavaScript, Python y SQL corren en tu navegador. Java, C++ y otros lenguajes compilados se ejecutan en un servidor Judge0.

Windows, Mac, Linux, Android, iPhone y iPad. Una vez instalado abre sin internet.

Atajos de Notepad++

F5 para ejecutar, Ctrl+\ para dividir el panel, Alt+M para mover una pestaña. Si vienes de Notepad++, ya sabes usarlo.
