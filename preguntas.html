Preguntas frecuentes

¿Cuánto cuesta?

Nada. Multipad es gratis y no necesitas crear una cuenta.

¿Qué diferencia hay entre instalar desde el navegador y descargar el instalador?

Es el mismo editor. Desde el navegador tarda un minuto, ocupa poco espacio y se actualiza solo. El instalador es un archivo que instalas como cualquier programa y no depende de que tengas Chrome o Edge.

¿Dónde se guardan mis archivos?

Lo que escribes se guarda en el almacenamiento del navegador de ese dispositivo. Al guardar con Ctrl+S, Chrome y Edge de escritorio escriben directo en el archivo original; en Android, Firefox y iPhone se descarga una copia.

¿Mi código sale de mi computadora?

Solo si ejecutas un lenguaje compilado (Java, C++, C# y otros), porque ese código se envía al servidor Judge0. HTML, CSS, JavaScript, Python y SQL corren dentro de tu dispositivo.

¿Puedo usar dos monitores en una tablet?

Depende del sistema. En Android puedes usar pantalla dividida con dos ventanas de Chrome; en iPad, Split View de Safari con dos pestañas de Multipad.

¿Funciona sin internet?

Sí, una vez instalado. Python y SQL necesitan internet la primera vez que los usas, y los lenguajes compilados siempre, porque corren en Judge0.
